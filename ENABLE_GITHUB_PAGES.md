# Enable GitHub Pages - Quick Setup Guide

Your housing data globe visualization is ready to go live! Follow these simple steps to make it public:

## Steps to Enable GitHub Pages:

1. **Go to your repository on GitHub:**
   - Visit: https://github.com/olivianielsen15/global-housing

2. **Open Repository Settings:**
   - Click the "Settings" tab (top right of the repository page)

3. **Navigate to Pages:**
   - In the left sidebar, scroll down and click "Pages"

4. **Configure GitHub Pages:**
   - Under "Source", select the branch: **`claude/housing-data-globe-map-mKiDo`**
   - Keep the folder as: **`/ (root)`**
   - Click **"Save"**

5. **Wait for Deployment (1-2 minutes):**
   - GitHub will build and deploy your site
   - A green success message will appear with your site URL

## Your Public URL Will Be:

```
https://olivianielsen15.github.io/global-housing/
```

## What You'll Get:

✓ Interactive 3D globe with 75 countries
✓ 4 data layers (Housing Deficit, Mortgage/GDP, Govt Expenditure, Construction Jobs)
✓ 20 African countries with CAHF data
✓ Real-time tooltips and statistics
✓ Auto-rotating globe visualization

## Troubleshooting:

- **404 Error?** Wait 2-3 minutes for the first deployment to complete
- **Changes not showing?** GitHub Pages may take a few minutes to reflect updates
- **Build failed?** Check that all files (index.html, app.js, data.js, styles.css) are in the root directory

---

That's it! Your housing data visualization will be live and publicly accessible at the URL above.
