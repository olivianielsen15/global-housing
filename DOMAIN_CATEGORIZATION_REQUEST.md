## Description Template:

Use this when submitting:

```
Site Name: Global Housing Data Visualization
URL: https://globalhousingdatabase.com
Category: Education / Reference / Research

Description:
Educational data visualization platform displaying housing metrics across 91 countries.
Data sourced from reputable international organizations (OECD, World Bank, UN-Habitat,
IMF, WorldRiskReport). Used by researchers, policymakers, and students for housing
policy analysis. Non-commercial, educational resource.

Content: Interactive 3D globe visualization with housing affordability, deficit,
construction activity, and investment opportunity data.
```
